Key results

Flagship cross-jurisdiction chain

GALAXY ASIA LIMITED. ↔ TO.CE.CO LIMITED. — a clean 3-hop path: VGB company → HKG intermediary → HKG address → HKG company; score 9.35 (offshore) / 10.45 (icij). Two jurisdictions crossed, every hop explainable.

Hub filter inside the traversal

A post-hoc Python filter over an unfiltered path list timed out at 60 s next to the 36k-degree hub; the in-traversal prune (WHERE n.degree_core <= $hub in the MATCH pattern) returns in milliseconds — measured on the loaded graph.

Panama Papers on the same schema

The union icij graph — Offshore Leaks + Panama Papers, 838,293 nodes / 1,286,362 edges — answers cross-dataset questions, with the single deliberate same_as link presented as a possible match.

One record per ID

The 1,139 IDs ICIJ reuses across the officer and intermediary files are stored as one node with both labels (verified identical names and country codes in all 1,139 cases) — answers never count the same record twice.

What’s next

  • More datasets — the same schema and tools over further ICIJ releases and comparable registries.
  • A hosted graph — so the demo does not rely on a local Docker container.
  • Memory across sessions — follow-up questions that keep the users-pinned records and earlier paths in context.

These are future work — none of them is built in this submission.
