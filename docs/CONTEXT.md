## Gotchas and fixes
- `.env` DATA_DIR line has a **doubled prefix** (`DATA_DIR=DATA_DIR=...`), found content-blind (grep counts, file never displayed) during Phase 4a. Python side survives (prepare_slice never loads .env; defaults are right), but ANY `${DATA_DIR}` interpolation in `docker-compose.yml` makes every compose command fail with `refers to undefined volume DATA_DIR=...`. The compose file therefore keeps the hardcoded dev import-root path on purpose. **Viraj: fix the line to a single `DATA_DIR=` before ever using interpolation.**
- The tmux uvicorn process was restarted 2026-10-18 during Phase 3f and now serves the current code (0a/0b + 3f). After any further backend change, restart it again with the documented pattern (kill and start as SEPARATE commands) or the old behaviour shows.
- UI score table shows stale cached entries defensively now: a missing/non-finite `score` renders the `score_note` (or "n/a (no path)") instead of `NaN`; missing per-node weights render "—".
- falkordb 1.8.0: delete a test graph via `Graph.delete()` (`db.select_graph(name).delete()`); the client has no `delete_graph`.
- `git commit -m "..."` message truncates through wsl quoting → write message to a file, `commit -F <file>`, then remove the file.
- FalkorDB shortestPath() is directed-only and MATCH-scoped (WITH/RETURN form); undirected var-length MATCH with WHERE all() filters after hub expansion (60s timeout at 36k hub) — prune with per-hop predicates instead. Bounded algo.SPpaths also uses DFS enumeration (timed out 60s); unbounded takes the Dijkstra fast path — never pass maxLen to the reference call.
- MCP v2 Tool uses input_schema (snake_case); empty-string short-circuit missing-property filters fail silently — branch query shapes in Python; "already indexed" (not "already exists") is the idempotent fulltext message.
- RediSearch: quoted phrases with punctuation raise syntax errors (never quote user input); commas/hyphens tokenize loosely (one query hit 50 noise rows) — union raw + punctuation-stripped variants, exact-first.
- pkill -f matches your own shell cmdline (suicide, empty output) — use a bracket pattern; stale uvicorn on :8000 shows "address already in use" in runs/uvicorn.log. The bracket trick still fails if the SAME command line also starts uvicorn (the literal "uvicorn backend.app.main" in the start half matches): run the kill and the start as SEPARATE commands, then confirm with /health.
- 61s agent runs = Groq 429 OTPM-1000 retries on qwen3-27b on_demand (code itself ~0.5s: startup 0.5s, search 0.0s, strongest 0.2s, trivial LLM 0.7s) — provider/model cause, not worked around; cache sidesteps repeats.
- Address records carry street text in the address field with empty names — name search cannot resolve hub addresses; test set documents this instead of routing around it.
- Docker Desktop can be fully down (no daemon): relaunch the per-user exe, then `docker compose up -d`; background servers need setsid to survive the shell (nohup alone died). 2026-10-17 update: even `setsid`+`&` from the agent tool wrapper gets reaped — start uvicorn with tmux: `tmux new-session -d -s uvicorn '.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 >> runs/uvicorn.log 2>&1'`, then confirm `/health`.
- FalkorDB volume: the image persists in `/var/lib/falkordb/data` (symlinked from `/data/data`), so the named volume must be mounted at BOTH paths or any container recreate silently empties every graph (happened once; recovery = reload from the untouched prepared folder, 14s). After any `--drop` reload also run `ensure_search_indexes()` (`runs/ensure_idx.py` pattern, `GRAPH_NAME=icij` for the union) or name search returns 0 hits.
- Bulk loads: `FALKORDB_ARGS` in the image ships `TIMEOUT 1000` (ms) — raise with `docker exec <c> redis-cli GRAPH.CONFIG SET TIMEOUT 600000` before loading a graph, and expect to redo this after every container recreate (it is not persisted).
- LOAD CSV resolves URIs ONLY at the import root; `../`, absolute paths, and mounts nested under a `:ro` parent all fail. The import root is `DATA_DIR/import_root` (hardlinks of `prepared/*` + `prepared_icij/*` under `icij/`); after regenerating a prepared folder, re-create its hardlinks (`cp -l <prepared>/* import_root/[icij/]`).
- Node ids are STRINGS in the graph (CSV-sourced): ad-hoc Cypher probes must quote them (`{node_id: '290583'}` or string params); the tools always pass them back as returned by search, so they are unaffected.
- `scripts/try_tools.py` now imports `backend.graph.*` with `sys.path.insert(0, ".")` — keep new graph-layer imports in the `backend.graph.x` style (agent/app/MCP all use that style).
- WSL `docker` CLI depends on Desktop's per-distro integration: if `wsl docker` fails but Windows `docker` works, re-enable Ubuntu integration (or restart Desktop); containers created while it was off can carry empty bind mounts → `--force-recreate` after fixing.
- Keep outputs small: summaries only, never dump raw CSV rows (max 3 lines per file).
- Multi-line `python - <<'EOF'` heredocs get mangled going PowerShell -> wsl (parentheses/quotes break); write the snippet to a file under the gitignored `runs/` and run it, then delete it.
- Cytoscape style selectors need data-mapped colours to exist on every element (node and edge both carry `bg`/`edgeColor`/`softColor` etc.); breadthfirst needs `roots` set before `buildGraph` or it has no anchor.
- Cytoscape node/edge colours live in element DATA, so a theme change must rewrite each element's data before re-applying the stylesheet (`cy.style().fromJson(graphStyle()).update()`) — swapping CSS alone changes nothing on the canvas.
- `cy.png()` in the vendored 3.34.4 has no `output:"base64uri"` case: unknown output values fall through to the default, which returns the full data URI (what `<a download>` needs); `output:"base64"` returns raw base64 without the prefix.
- `get_neighbors` returns the RELATIONSHIP sourceID as `rel_sourceID` (its `sourceID` key is the neighbour NODE's own source); the UI maps `rel_sourceID || sourceID` so an expansion edge card shows the right record source.
- The UI action buttons must be reached through the node-select model (tap node → tap second node → bar appears); `updateActions` is the only place the bar is filled, and an empty-canvas tap resets selection + highlight.
- Zoom baseline: `card.baseZoom` is captured ONLY in `markBase` (cy `layoutstop`, the 60ms full-screen refit) and "100%" resets to it, so any future code path that relayouts/resizes a card without a `layoutstop` or a `markBase` call will leave 100% pointing at a stale zoom. The explicit Fit button intentionally does not re-baseline.
- Cached answers can go stale when a TOOL changes: the T5Q3 cache said "no exact match" after the 2e search-variant fix let "Tsai, Eng-Meng" resolve exactly. After any tool/search change, re-run the ★ demo questions fresh (the cache is overwritten on a fresh run) and re-grade their cached text.
